# matrix_24hr_clock
This is a clock that finds the time using the datetime module

![24hr clock](https://cloud-7j023a12a-hack-club-bot.vercel.app/0oie_ers9q4hwaguk.png)

![24 clock night](https://cloud-6ob2rh5dm-hack-club-bot.vercel.app/0oie_l79nyed1waoc.png)

- At 6pm (evening) the screen goes a darker shade of blue with a moon, stars sparkle randomly on screen.
- At 6am (morning) the screen resets into a light blue with a sun, clouds move across screen right to left

  This was made for hackclub neon (https://neon.hackclub.dev/)
