# matrix_24hr_clock
This is a clock that finds the time using the datetime module

![24hr clock](https://cloud-93mrw1n8w-hack-club-bot.vercel.app/0image.png)

- At 6pm (evening) the screen goes a darker shade of blue
- At 6am (morning) the screen resets into a light blue

  This was made for hackclub neon (https://neon.hackclub.dev/)
